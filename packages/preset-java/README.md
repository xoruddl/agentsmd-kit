# @agentsmd/preset-java

[`@agentsmd/cli`](https://www.npmjs.com/package/@agentsmd/cli)의 Java·Gradle 프리셋입니다.

```bash
npx @agentsmd/cli init --preset java
```

- 문서 지도(`AGENTS.md`)와 Java 코드 규칙: 코드 스타일, 클린 코드 원칙과 예시, Java 체크리스트
- palantir-java-format(Spotless) 커밋 검사, Gradle CI
- [공통 Git 프리셋](https://www.npmjs.com/package/@agentsmd/preset-git)이 함께 설치됩니다.
